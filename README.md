# gb-demo-app

Демонстрационный full-stack проект, созданный как Nx-монорепозиторий. Сейчас это стартовый шаблон без прикладной бизнес-логики.

В репозитории находятся:

- `apps/web` — React 18 клиент с React Router. Он показывает стандартную welcome-страницу Nx и две демонстрационные страницы: `/` и `/page-2`.
- `apps/api` — NestJS 9 API. Единственный маршрут `GET /api` возвращает JSON `{ "message": "Welcome to api!" }`.
- `apps/web-e2e` — заготовка Cypress для end-to-end теста веб-приложения.
- `libs` — место для общих библиотек; сейчас оно пустое.

Фронтенд и API пока не связаны: веб-приложение не отправляет запросы к API.

## Требования

- Node.js 18 или 20
- npm

Проект использует Nx 15 и зафиксированные версии зависимостей из `package-lock.json`. На более новых версиях Node.js этот старый набор инструментов может работать нестабильно.

## Установка

```bash
npm ci
```

## Локальный запуск

Запустить frontend и API одновременно:

```bash
npm start
```

После запуска доступны:

- frontend: <http://localhost:4200>
- API: <http://localhost:3001/api>

Сервисы можно запускать отдельно:

```bash
npm run start:api
npm run start:web
```

При отдельном запуске `start:web` frontend открывается на <http://localhost:3002>.

Порт API можно изменить переменной окружения:

```bash
PORT=4000 npm run start:api
```

## Сборка

Production-сборка обоих приложений:

```bash
npm run build
```

Сборка отдельных приложений:

```bash
npm run build:api
npm run build:web
```

Результат создается в `dist/apps/api` и `dist/apps/web`.

## Тесты

Запустить unit-тесты API и frontend:

```bash
npm test
```

Или по отдельности:

```bash
npm run test:api
npm run test:web
```

Запуск Cypress e2e-теста:

```bash
npx nx e2e web-e2e
```



Сейчас это учебная заготовка для разработки full-stack приложений на TypeScript.

Её можно использовать как основу для:

- личного кабинета или админ-панели;
- небольшого интернет-магазина;
- CRM или внутреннего корпоративного сервиса;
- трекера задач;
- каталога товаров или контента;
- прототипа SaaS-продукта;
- демонстрации связки React + NestJS.

Архитектура уже разделена на части:

- web — пользовательский интерфейс;
- api — серверная логика и будущая работа с базой данных;
- web-e2e — браузерные тесты;
- libs — место для общего кода и типов.

При этом сейчас полезной функциональности почти нет: frontend показывает стандартную страницу Nx, а API возвращает только приветствие. В проекте пока отсутствуют база данных, авторизация, бизнес-сущности и связь frontend с API.

То есть это не готовый продукт, а технический стартовый шаблон. Следующим шагом обычно выбирают конкретный сценарий, добавляют модели данных, базу, API-методы и интерфейс.
