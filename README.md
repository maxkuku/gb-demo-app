# Северное сияние

Демонстрационный интернет-магазин коллекционных новогодних украшений. Проект построен как Nx-монорепозиторий на React и NestJS.

## Возможности

- каталог из 19 ёлочных игрушек с фотографиями, названиями, описаниями и ценами;
- фильтрация по категориям: шары, подвесы и фигурки;
- адаптивная витрина для компьютеров и мобильных устройств;
- корзина с изменением количества товаров и подсчётом суммы;
- демонстрационная форма оформления заказа;
- подарочный и информационный разделы.

Форма заказа пока работает только как демонстрация: данные не отправляются, оплата и хранение заказов не подключены.

## Структура

- `apps/web` — React 18 интернет-магазин;
- `apps/api` — NestJS 9 API с тестовым маршрутом `GET /api`;
- `apps/web-e2e` — Cypress-заготовка для e2e-тестов;
- `toys` — исходные фотографии товаров;
- `apps/web/src/assets/toys` — оптимизированные WebP-версии для сайта.

## Требования

- Node.js 18 или 20;
- npm.

Проект использует Nx 15. На более новых версиях Node.js этот старый набор инструментов может работать нестабильно.

## Установка

```bash
npm ci
```

## Запуск магазина

```bash
npm run start:web
```

Магазин откроется на <http://localhost:3002>.

Запустить frontend и API одновременно:

```bash
npm start
```

В этом режиме доступны:

- frontend: <http://localhost:4200>;
- API: <http://localhost:3001/api>.

## Сборка

```bash
npm run build
```

Собрать только магазин:

```bash
npm run build:web
```

Результат создаётся в `dist/apps/web`.

## Тесты

```bash
npm test
```

Или отдельно:

```bash
npm run test:web
npm run test:api
```
